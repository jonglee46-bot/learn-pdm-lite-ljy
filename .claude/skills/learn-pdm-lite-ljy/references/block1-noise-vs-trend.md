# Block 1: 노이즈 vs 추세

> **Phase A 시작 시 그대로 출력한다:**
> ```
> 📖 공식 문서: https://github.com/keerhee/kma-auto-genai-3-1/tree/main/Day5_예지보전

## EXPLAIN

### 1. 노이즈와 추세

| 용어 | 뜻 |
|---|---|
| 노이즈 | 한 번 튀고 곧 정상으로 돌아오는 일시적 값. 측정 오류·순간 외란일 수 있다 |
| 추세 | 임계선을 향해 꾸준히 오르는 흐름 |
| 평상 범위 | 평균 ± 2 × 표준편차. 벗어난 값을 이상 후보로 표시한다 |
| 기준선 | 처음 12점(08:00~11:40). 평소 상태로 삼는 구간이다 |
| 기준선 상한 | 기준선의 평균 + 3 × 표준편차 |
| 판정 규칙 | 기준선 상한을 3번 연속 넘으면 추세, 넘었지만 3번 연속이 아니면 노이즈. 추세의 첫 시각이 추세 시작이다 |

### 2. 왜 한 점이 아니라 흐름을 보는가

| 기준 | 한 점으로 판단 | 흐름으로 판단 |
|---|---|---|
| 신호 | 가장 높은 값 | 임계선을 향해 꾸준히 오르는 흐름의 시작점 |
| 잘못 보기 쉬운 것 | "한 번 높았으니 위험"으로 노이즈와 추세를 혼동한다 | 한 점의 이상치는 정비 신호로 보지 않는다 |
| 얻는 것 | 이미 많이 오른 뒤에야 잡힌다 | "고장 전 계획 정비"의 기준점을 얻는다 |

### 3. 케이스 — 데이터가 사고를 막다

한 제조사가 설비 진동 데이터를 상시 감시했다. 평소와 다른 미세한 진동 증가를 포착해 고장 직전 부품을 교체했고, 그대로 뒀다면 며칠치 생산이 날아갈 상황을 막았다. 예지보전의 가치는 고장을 0으로 만드는 것이 아니라 고장을 미리 알아 계획적으로 대응하는 것이다.

## EXECUTE

아래 프롬프트를 붙여 넣으라고 안내한다.

```
pdm-lite-lab/data 의 Day5_설비센서_50건_가상.csv 로 설비A와 설비B가 노이즈인지 추세인지 판정해 줘. 원본은 고치지 마.
1. 설비별·센서별(진동·온도·압력)로 처음 12점(08:00~11:40)을 기준선으로 삼아 기준선 상한 = 평균 + 3 × 표본 표준편차 를 구해 줘.
2. 상한을 3번 연속 넘으면 '추세', 넘었지만 3번 연속이 아니면 '노이즈', 넘지 않으면 '정상'으로 판정하고, 추세의 첫 시각을 '추세 시작'으로 pdm-lite-lab/outputs/trend_judgement.csv 에 저장해 줘.
3. 설비A 진동, 설비B 진동, 설비B 온도를 시간순 선 그래프 한 장으로 그려 pdm-lite-lab/outputs/chart.html 로 저장하고 열어 줘. 온도는 오른쪽 축을 쓰고 설비B 온도의 기준선 상한도 그려 줘.
4. 평상 범위(25점 전체의 평균 ± 2 × 표본 표준편차)로 처음 잡힌 설비B 시각보다 가장 이른 추세 시작이 몇 분 빠른지 알려 줘.
```

### 확인할 것 (Phase B)

- `pdm-lite-lab/outputs/trend_judgement.csv`에서 설비B 온도 추세 시작이 `13:00`이다.
- 같은 파일에서 설비B 진동 추세 시작이 `15:00`이다.
- 같은 파일에서 설비A 진동 판정이 `노이즈`이다.
- 가장 이른 추세 시작이 평상 범위 첫 포착보다 `160`분 빠르다.
- 설비B 온도 기준선 상한이 57.0℃이다.
- `pdm-lite-lab/outputs/chart.html`이 있고 선 세 개가 그려진다.

막히면 "방금 결과가 원본 판정 규칙과 다른 곳을 찾아 원인을 한 줄씩 설명하고 고쳐 줘"를 붙여 넣게 한다. 정답은 "정답 보기" 요청이 있을 때만 연다.

## QUIZ

```json
AskUserQuestion({
  "questions": [{
    "question": "이번 주 계획 정비를 한 대만 잡을 수 있다. 최근 다섯 시점의 진동(mm/s)이 설비A는 1.0→1.1→0.9→3.5→1.0, 설비B는 1.0→1.3→1.7→2.2→2.9이다. 어느 설비를 잡을까?",
    "header": "Quiz 1",
    "options": [
      {"label": "설비A", "description": "가장 높은 값이 3.5다"},
      {"label": "설비B", "description": "값이 꾸준히 오르고 있다"}
    ],
    "multiSelect": false
  }]
})
```

정답: 2번. 설비B는 임계선을 향해 꾸준히 오르는 추세적 상승이고, 이 상승의 시작점이 진짜 정비 신호다. 설비A의 3.5는 한 번 튀고 곧 정상으로 돌아온 일시적 노이즈이며, "한 번 높았으니 위험"은 노이즈와 추세를 혼동한 것이다. 현장에서는 가장 높은 값을 고르지 않고, 흐름의 시작점을 "고장 전 계획 정비"의 기준점으로 삼는다.

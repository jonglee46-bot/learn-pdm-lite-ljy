# Block 2: 공개

> **Phase A 시작 시 그대로 출력한다:**
> ```
> 📖 공식 문서: https://docs.github.com/pages
> ```

## EXPLAIN

### 1. 공개에 쓰는 말

| 용어 | 뜻 |
|---|---|
| GitHub Pages | GitHub 저장소의 `index.html`을 웹 주소로 보여 주는 기능 |
| 설치 한 줄 | 동료가 붙여 넣어 이 강의를 자기 컴퓨터에 설치하는 한 줄 |

### 2. 왜 파일이 아니라 주소로 나누는가

| 기준 | 파일을 보낸다 | 주소와 설치 한 줄을 보낸다 |
|---|---|---|
| 받는 사람 | 파일을 받아 열어야 한다 | 주소를 열고, 설치 한 줄로 같은 수업을 듣는다 |
| 고친 뒤 | 다시 보내야 한다 | 다시 올리면 같은 주소에 반영된다 |

### 3. 공개 전 수칙

저장소를 공개하면 누구나 볼 수 있다. 이 수업의 데이터는 가상이지만, 내 업무로 바꿔 만들 때는 회사 내부 자료를 공개 저장소에 넣지 않는다. 로그인 일회용 코드는 브라우저 칸에만 친다.

## EXECUTE

```
이 강의의 공개 상태를 확인해 줘. 새 저장소는 만들지 말고, 아무것도 올리지 마.
1. 대시보드 주소 https://jonglee46-bot.github.io/learn-pdm-lite-ljy/ 가 열리는지 확인해 줘.
2. 아래 설치 한 줄을 그대로 보여 줘.
   npx skills add jonglee46-bot/learn-pdm-lite-ljy --agent claude-code --global --yes
3. 내 그래프 pdm-lite-lab/outputs/chart.html 이 대시보드와 같은 내용인지 한 줄로 알려 줘.
```

### 확인할 것 (Phase B)

- 대시보드 주소가 응답한다.
- 설치 한 줄이 위와 같다.

주소가 안 열리면 "대시보드 주소가 안 열려. Pages 상태를 확인해 줘"를 붙여 넣게 한다. 확인이 끝나면 대시보드 주소를 다시 보여 주고 "수업 끝"을 출력한다.

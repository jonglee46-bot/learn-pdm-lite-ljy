## EXPLAIN

### 1. 오늘 쓰는 말

| 용어 | 뜻 |
|---|---|
| 예지보전 | 고장 후 고치거나 주기 점검을 하는 대신, 센서로 고장 징후를 미리 감지해 정비 시점을 조정하는 것 |
| 다변수 센서 데이터 | 진동·온도·압력처럼 여러 변수를 동시에 시간 순으로 기록한 것 |
| 실습 데이터 | 설비 2대 × 25시점, 모두 50건의 **가상** 데이터. 설비A는 프레스 메인모터, 설비B는 차체 용접로봇 감속기 |

### 2. 왜 단위부터 확인하는가

| 기준 | 바로 분석 | 먼저 점검 |
|---|---|---|
| 단위 | 섞여 있어도 모른다 | ℃, mm/s, bar를 먼저 확인한다 |
| 측정 주기 | 시점 간격을 모른다 | 측정 주기(20분)를 먼저 확인한다 |
| 결과 | 단위가 섞이면 이상 판단이 흔들린다 | 같은 기준으로 판단한다 |

### 3. 왜 미리 보는가

조립 라인은 한 곳이 멈추면 뒤 공정이 줄줄이 멈춘다. 라인 정지 1분 손실이 수천만 원이라, 고장을 미리 아는 것은 비용이 아니라 생존의 문제다.

## EXECUTE

아래 프롬프트를 붙여 넣으라고 안내한다. `{SKILL_DIR}`는 Phase A 출력 직전에 이 스킬 폴더의 실제 경로로 바꿔 보여 준다.

```
수업 실습을 준비해 줘.
1. 지금 폴더 아래 pdm-lite-lab/data 와 pdm-lite-lab/outputs 폴더를 만들어 줘.
2. {SKILL_DIR}/assets/lab/Day5_설비센서_50건_가상.csv 를 pdm-lite-lab/data 로 복사해 줘. 원본은 고치지 마.
3. 복사한 csv의 행 수, 설비 수, 단위, 측정 주기를 확인해 줘.
4. 확인 결과를 pdm-lite-lab/env_check.txt 에 저장하고 한 줄로 알려 줘.
```

### 확인할 것 (Phase B)

- `pdm-lite-lab/data/Day5_설비센서_50건_가상.csv`가 있고 데이터가 50행이다.
- 설비가 2대이고 설비마다 25시점이다.
- `pdm-lite-lab/env_check.txt`가 있다.

막히면 "방금 오류의 원인과 해결을 한 줄씩 설명한 뒤 고쳐 줘"를 붙여 넣게 한다. 정답은 "정답 보기" 요청이 있을 때만 연다.
